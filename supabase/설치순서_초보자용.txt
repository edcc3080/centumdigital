센텀디지털캠프 관리자 페이지 연결 순서
========================================

이 ZIP에는 관리자 화면과 기능 코드가 모두 들어 있습니다.
다만 실제 데이터 저장을 위해 Supabase 프로젝트 1개를 만들어 연결해야 합니다.

[1] Supabase 프로젝트 만들기
- https://supabase.com 접속
- 새 프로젝트 생성
- 프로젝트가 만들어질 때까지 기다립니다.

[2] 데이터베이스 만들기
- Supabase Dashboard → SQL Editor
- 이 ZIP의 supabase/schema.sql 내용을 전부 붙여넣고 실행합니다.
- posts, suggestions, admin_users 테이블과 post-images 저장공간/보안정책이 만들어집니다.

[3] 관리자 로그인 계정 만들기
- Supabase Dashboard → Authentication → Users
- 관리자용 이메일/비밀번호 사용자를 직접 추가합니다.
- 일반 방문자용 회원가입 기능은 만들 필요 없습니다.

[4] 그 계정을 관리자 권한으로 등록
- SQL Editor에서 아래 문장의 이메일만 실제 관리자 이메일로 바꾸어 실행합니다.

insert into public.admin_users (user_id, display_name)
select id, '센텀디지털캠프 관리자'
from auth.users
where email = '여기에_관리자_이메일'
on conflict (user_id) do nothing;

[5] 홈페이지와 Supabase 연결
- Supabase의 Project URL
- Publishable key 또는 anon key
를 확인합니다.

- GitHub Codespaces에서:
  assets/supabase-config.js
를 열어 아래 2줄을 교체합니다.

export const SUPABASE_URL = "https://YOUR_PROJECT_ID.supabase.co";
export const SUPABASE_PUBLISHABLE_KEY = "YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY";

중요:
service_role key는 절대로 홈페이지 코드에 넣지 마세요.

[6] GitHub에 올리고 테스트
관리자 로그인 주소:
https://edcc3080.github.io/centumdigital/admin/login.html

테스트 순서:
1. 관리자 로그인
2. 새 글 작성
3. 카테고리 선택
4. 제목/본문 입력
5. 사진 선택
6. 홈페이지 공개 체크
7. 저장
8. 해당 메뉴에서 글이 나타나는지 확인

[관리자에서 올린 글이 나타나는 위치]
공지사항 → 공지사항/notice.html
개강 안내 → 공지사항/open.html
모집중인 과정 → 공지사항/recruit.html
교육 일정 → 공지사항/schedule.html
자료실 → 공지사항/data.html

수강생 후기 → 커뮤니티/review.html
수강생 작품 → 커뮤니티/work.html
취업·창업 이야기 → 커뮤니티/job.html
포토갤러리 → 커뮤니티/gallery.html

[건의함]
방문자:
커뮤니티/suggestion.html 에서 익명 또는 실명으로 제출

관리자:
admin/suggestions.html 에서
- 내용 확인
- 새 건의
- 확인 중
- 처리 완료
- 삭제
관리가 가능합니다.

[사진]
대표 사진 1장 + 추가 사진 여러 장을 올릴 수 있습니다.
사진은 Supabase Storage의 post-images에 저장되고,
게시글 내용은 posts 테이블에 저장됩니다.

[일반 회원가입]
필요 없습니다.
현재 구조는 직원 관리자만 로그인합니다.
방문자는 로그인 없이 홈페이지 열람과 건의함 제출만 합니다.
